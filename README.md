EduTech - Online Learning Platform
This is my web development assignment project. It is a frontend dashboard for an online education website built using only basic HTML, CSS, and JavaScript.

What It Does
The website simulates a student portal where users can browse courses, see their enrolled classes, and track their learning progress. I built it to practice 
DOM manipulation and basic layout styling.

Main Features
Course Library: Displays available courses (UI/UX Design, Photography, Architecture) with descriptions.

Favorite Filter: Clicking the "Favourite" tab or sidebar link uses JavaScript to hide other courses and only show the favorite ones. 
Clicking "All Courses" brings them all back.

Enrollment Buttons: Clicking "Enroll Now" on a course card changes the button text to "Enrolled" and updates the active course box at the bottom to show 
the selected course title and total lessons.

Progress Tracker: A visual tracker in the bottom section that shows a static 40% completion circle and progress bar for the active course.

Sidebar Menu: A navigation menu containing a student profile picture, name, and basic links.

Technologies Used
HTML: For structuring the dashboard, sidebar, and cards.

CSS: For styling, placing elements side-by-side using basic layouts, standard color naming, and hover effects.

JavaScript: For the interactive parts like filtering the favorite courses and changing text elements when a button is clicked.

How to Run
You do not need any local server, backend, or installations to run this project.

Download all the files (project.html, ProjectCSS.css, ProjectJS.js, and the JPG images) into one single folder.

Double-click project.html to open it in Chrome, Edge, or any web browser.
